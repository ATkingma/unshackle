# Agent pool plan — 2026-10-22

Dispatch plan for running TAAK-301..310 with a pool of sub-agents. The main session dispatches, merges one by one,
runs `verify-head.sh`, pushes and watches CI. Agents never push to `main`.

## Rules for every agent

- Work in its own worktree (`isolation: worktree`), effort low unless stated. Read `CLAUDE.md`, `claude/docs/overdracht.md`
  and its task file first; pick up with `/taak-oppakken TAAK-NNN`.
- Touch only the files in its **Owns** column. Shared files (`claude/docs/INDEX.md`, `claude/docs/overdracht.md`,
  `claude/docs/council.md`, `docs/projectinfo/project.md`, `Directory.Packages.props`, `Unshackle.slnx`, `Cli.cs`) are
  edited by the main session only: an agent lists the lines it wants there in its final report.
- New tasks only with numbers from its **Reserved** range.
- A design choice goes in the final report as a council question; the agent does not decide it.
- `TEMP`/`TMP` on a `D:` folder (this machine blocks `.exe` from `%TEMP%`); never kill other dotnet processes.
- Corpus clones go under `<corpus>/corpus-<lib>/` (`D:/playground/corpus-<lib>/` here), never in the repo.
- Done = build 0 warnings, all tests green, task file updated (progress log, status), committed in the worktree.
