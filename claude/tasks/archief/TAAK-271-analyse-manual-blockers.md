# TAAK-271 — Analyse every Manual finding that blocks a migration

**Status**: ✅ done — 2026-10-17
**Created**: 2026-10-17
**Goal**: a complete, counted list of every Manual finding in the 8 blocked blind-corpus repos and SampleShop, each classified as _solvable with proof_ (and by which task) or _principally manual_ (with the reason).

## Context for the next agent

- Queue and proof rules: `claude/tasks/manual-reduction-queue.md`.
- Blocked repos (`claude/tasks/CORPUSRUN-blind.md`): MediatR fullcart, miru, starter; AutoMapper culinary, msb, fiapgames, restapi, baseapi. Clones/harness: see that file (corpus on the large data disk, `<corpus>`; never `/tmp`).
- The all-or-nothing rule (MediatR/AutoMapper per solution) lives in `src/Unshackle.Core/Fixer.cs`, `Abstractions/IFix.cs`, `Fixes/MediatR/MediatRFix.cs`, `Fixes/AutoMapper/AutoMapperFix.cs`.

## Method

- Tool published from this branch (no product change relative to `main` at `36c9908`) into `<corpus>/_results/271/tool`; `claude/tools/corpus-am.sh list scan` on the 8 repos (restore, build, `scan --fix <fix> --report`), plus `scan` on `samples/SampleShop/SampleShop.slnx` with all three fixes. Reports: `<corpus>/_results/271/<repo>.json`, `sampleshop-<fix>.json`.
- Every finding is attributed to its **root cause**. Three kinds of Manual finding exist: _root_ (the real obstacle), _dependent_ ("`CreateMap<A,B>` is in profile P, which this fix does not rewrite: <root reason>", or `IMapper`/usings/project-file leftovers) and _all-or-nothing_ ("Not rewritten: this fix changes nothing while other findings are Manual"). Only roots need work; the rest disappears with them.
- Behaviour was measured with probe programs against the real old versions (AutoMapper 14.0.0, Mediator 3.0.2 generator): `<corpus>/_results/271/probe-am`, `probe-mr` (not in the repo).
